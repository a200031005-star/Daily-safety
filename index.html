PC 화면 전용입니다

이 도구는 PC(데스크톱) 화면에 맞춰 만들어졌습니다.
모바일에서는 화면이 깨지거나 조작이 불편할 수 있으니,
가능하면 PC 화면에서 접속하시길 추천합니다.

사용법

헤드 · 배경 · 저장

  • 헤드·배경 설정: 현장명·작업일·배경사진을 펼쳐서 입력/변경
  • 저장·계획 버튼을 누르면 저장/다른 날짜로 저장/새 계획/이력 불러오기/이력 삭제 버튼이 펼쳐집니다
  • 배경사진은 삭제하기 전까지 다음 날짜에도 계속 이어서 사용됩니다
  • 저장: 현재 작업일 기준으로 저장(이미 있으면 덮어씀) → 이력 불러오기 드롭다운에서 날짜 선택하면 그 날 내용을 불러와 이어서 편집 가능, 다시 저장하면 그 날짜에 업데이트됩니다
  • 새 계획: 오늘 날짜로 빈 계획 시작 (장비/배경은 이어짐)
  • 다른 날짜로 저장: 이력을 불러와 수정한 뒤, 위쪽 "작업일" 칸에서 새 날짜를 선택하고 이 버튼을 누르면 원본 날짜는 그대로 두고 그 새 날짜로 별도 저장됩니다 (예: 어제 계획을 불러와 수정 후 내일 날짜로 저장)
  • 출력 버튼을 누르면 PDF / 사진(PNG) 중 골라서 현재 화면을 파일로 저장할 수 있습니다

말풍선

  • 추가 후 드래그로 이동, 더블클릭으로 텍스트 수정
  • 클릭(선택)하면 선택 표시와 함께 삭제·크기조절·특성 아이콘이 나타나며, 다른 곳을 클릭하기 전까지는 자동으로 사라지지 않음
  • "선 특성 선택"을 누르면 테두리 색상·두께·점선·박스 없애기가, "글자 특성 선택"을 누르면 글자크기(숫자 직접 입력 가능)·글자색이 펼쳐집니다
  • 우측 하단 모서리를 드래그하면 말풍선 크기(너비·높이)를 조절할 수 있습니다

장비

  • 우측 팔레트에서 클릭하면 캔버스에 추가됨
  • 아이콘 드래그로 이동, 이름표는 따로 드래그해서 위치 조정 가능
  • 이름표 더블클릭: 이름 수정 / 아이콘 더블클릭: 사진·이모지 변경
  • 클릭(선택)하면 회전·반전·복사·크기조절·삭제 버튼 표시
  • 우측 팔레트 장비는 ✎(수정)·×(삭제)로 종류 관리, "장비 초기화"로 기본 목록 복원

선 추가

  • 버튼을 누른 뒤 캔버스를 순서대로 클릭해 꺾은선을 그림
  • 더블클릭하거나 버튼을 다시 누르면 완성
  • 완성 후 클릭(선택)하면 색상·두께·점선·삭제 버튼 표시, 드래그로 전체 이동 가능

구역설정

  • ▭(사각형)/⬤(원형) 버튼을 누른 뒤 캔버스에서 드래그하면 구역이 그려짐
  • 완성 후 클릭(선택)하면 색상·두께·점선·삭제 버튼 표시, 드래그로 전체 이동 가능
⚠ 실시간 공동작업이 아직 꺼져 있습니다 (현재는 이 기기에만 저장됨).
1) Firebase 콘솔에서 프로젝트 생성 → Realtime Database만 "테스트 모드"로 켜세요. (Storage는 필요 없습니다 — 신용카드 등록 없이 무료로 사용 가능합니다)
2) 프로젝트 설정 → 웹 앱 추가 → firebaseConfig 값을 복사해서 이 파일 하단 스크립트의 const firebaseConfig = {...} 부분에 붙여넣고 저장하세요.
3) 저장 후 다시 열면 이 안내는 사라지고, 여러 명이 같은 파일(URL)로 접속 시 실시간으로 동기화됩니다.
